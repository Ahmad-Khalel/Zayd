# موقع ثانوية زيد بن حارثة

نسخة مستقلة من الموقع مبنية فقط باستخدام:

- HTML5
- CSS3
- JavaScript Vanilla

لا يحتاج الموقع إلى React أو Vite أو Node.js أو قاعدة بيانات. يمكن تشغيله مباشرة بالنقر المزدوج على ملف `index.html`.

## التشغيل

1. فك ضغط الأرشيف.
2. افتح مجلد `zayd-school-html`.
3. افتح ملف `index.html` في المتصفح.

يفضل إبقاء مجلد `assets` بجانب `index.html` حتى تظهر الشعارات والملفات بشكل صحيح.

## الصفحات المتاحة

- الرئيسية
- عن المدرسة
- الانتساب والتسجيل
- المناهج الشرعية والأكاديمية
- الأخبار والإعلانات
- التبرع
- تواصل معنا
- بوابة الأهل
- لوحة الإدارة التجريبية

التنقل بين الصفحات يتم من خلال العناوين الموجودة بعد علامة `#` في الرابط، لذلك لا يحتاج الموقع إلى خادم.

## الحسابات التجريبية

بوابة الأهل:

- اسم المستخدم: `parent`
- كلمة المرور: `demo123`

لوحة الإدارة:

- اسم المستخدم: `admin`
- كلمة المرور: `demo123`

هذه الحسابات للتجربة فقط. لا تستخدم لوحة الإدارة الحالية لحفظ بيانات حساسة أو حقيقية؛ فهي تحفظ البيانات داخل متصفح الجهاز باستخدام `localStorage`.

## تعديل محتوى الموقع

افتح ملف `script.js` وعدّل:

- اسم المدرسة ومعلومات الاتصال داخل الكائن `SITE`.
- الأخبار داخل `defaultNews`.
- الطلاب التجريبيين داخل `defaultStudents`.
- مواد المنهج الشرعي داخل `defaultSharia`.
- مواد المنهج الأكاديمي داخل `defaultEducational`.

## التخزين والتصدير

طلبات التسجيل ورسائل التواصل وبعض تعديلات لوحة الإدارة تحفظ محلياً في المتصفح. من لوحة الإدارة يمكن:

- تصدير طلبات التسجيل إلى CSV.
- تصدير البيانات إلى JSON.
- استيراد نسخة JSON.
- حذف البيانات المحلية.

## الصور والملفات

ضع الصور والملفات داخل مجلد `assets`، ثم استخدم مساراً نسبياً مثل:

```text
assets/logo.png
assets/tajweed7.pdf
```

يمكن استبدال الصور الموجودة مع الحفاظ على أسماء الملفات، أو تعديل المسارات في `index.html` و`script.js`.

## ملاحظة مهمة

هذه نسخة ثابتة مناسبة للعرض والتجربة والاستضافة على خدمات الملفات الثابتة. إذا أردت استخدامها فعلياً لتخزين بيانات الطلاب أو تسجيل دخول حقيقي، يجب إضافة خادم وقاعدة بيانات ونظام مصادقة آمن وعدم الاعتماد على `localStorage`.
